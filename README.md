# Nishita Jakhotia — Web Design Portfolio

A responsive web design portfolio built with HTML, CSS and vanilla JavaScript. It features seven website projects already present in the parent workspace: Iron Peak Fitness, KIRO Studio, Secret Stories, Lumière Salon, Aurelia Café, Élevé Bakery and Shweta's Makeover. All portfolio files are in this folder's root; no build step or framework is required.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static server.

## Notes

- Project cards open details and link to their corresponding sibling website folders. Those links work when this portfolio remains beside the project folders in the workspace.
- Portfolio photography loads from Unsplash URLs and requires an internet connection.
- The inquiry form validates in the browser and displays a success state, but has no backend and does not transmit submissions. Use the listed email address for real inquiries.
- Social links are placeholders until the profile URLs are provided.
